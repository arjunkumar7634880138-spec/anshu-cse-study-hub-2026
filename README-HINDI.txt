ANSHU'S EXAM PREPARATION HUB – UPDATED VERSION

NAYE FEATURES:
1. Dashboard par student apna naam type karke “Show my name” dabaye. Naam turant sidebar/profile aur welcome heading par dikh jayega.
2. Settings page se bhi student apna naam badal sakta hai.
3. “CSE Class Routine” naam ka naya menu add kiya gaya hai. Isme aapke bheje hue CSE 1st Semester 2026 ke Monday-Saturday timetable ko period timings ke saath dikhaya gaya hai.
4. Original class timetable image bhi routine page ke neeche di gayi hai.
5. Timetable mobile par horizontal scroll ke saath dekha ja sakta hai.

CHALANE KA TARIKA:
1. ZIP file extract karein.
2. VS Code kholein aur extracted “Anshus_Exam_Preparation_Hub” folder open karein.
3. index.html ko browser me open karein ya VS Code me Live Server extension se “Open with Live Server” karein.
4. Dashboard par apna naam enter karke “Show my name” click karein.
5. Left menu me “CSE Class Routine” par click karke weekly timetable dekhein.

IMPORTANT:
- Naam aur study progress isi browser/device ke local storage me save hote hain.
- Alag student ke liye alag browser profile/device use karein, ya Settings me naam badlein.
- Multiple devices par cloud sync ke liye login + database backend alag se banana hoga.
- Original image me kuch handwritten timetable entries saaf nahi thi. Unhe ICT Tools/BEM ke roop me interpret kiya gaya hai; class teacher se verify kar lein.
